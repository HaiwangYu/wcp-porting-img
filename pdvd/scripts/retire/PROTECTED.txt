# union its inline keep set with every line below.  Removing a line is a
# deliberate decision; never remove one because a doc "already has the numbers"
# -- CLAUDE.md M13 protects the record, not the summary of it.
#

# Field 1 may hold several whitespace-separated names.

# RETIRED section at the bottom with the date; do not delete it.

# work-* dir: `work*` globs to ~200 dirs in sbnd_xin but to exactly ONE
# directory in pdvd.  A planner forked from the sbnd one gives dirs=0 or a
# single rm -rf work/.
